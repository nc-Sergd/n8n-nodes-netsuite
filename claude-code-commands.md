## 3. Флаги CLI

### 3.1. Сессия и продолжение

| Флаг | Описание |
|---|---|
| `-c, --continue` | Продолжить последний разговор в текущей директории |
| `-r, --resume [value]` | Возобновить по session ID или открыть интерактивный выбор |
| `--fork-session` | При возобновлении создать новый session ID вместо переиспользования |
| `--session-id <uuid>` | Использовать конкретный session ID (валидный UUID) |
| `-n, --name <name>` | Отображаемое имя сессии (в строке ввода, `/resume`, заголовке терминала) |
| `--no-session-persistence` | Не сохранять сессию на диск (только с `--print`) |
| `--from-pr [value]` | Возобновить сессию, привязанную к PR |
| `--teleport [session]` | Возобновить teleport-сессию |
| `--cloud [description\|session_id\|url]` | Создать облачную сессию или подключиться к существующей |
| `--environment <ccpool_...>` | Новая облачная сессия в указанном self-hosted окружении |
| `--bg, --background` | Стартовать как фоновый агент и сразу вернуть управление |
| `--remote-control [name]` | Интерактивная сессия с включённым Remote Control |
| `--remote-control-session-name-prefix <prefix>` | Префикс автогенерируемых имён Remote Control сессий |
| `-w, --worktree [name]` | Создать git worktree для этой сессии |
| `--tmux` | tmux-сессия для worktree (требует `--worktree`); `--tmux=classic` — обычный tmux |

### 3.2. Модель и поведение

| Флаг | Описание |
|---|---|
| `--model <model>` | Модель сессии: алиас (`fable`, `opus`, `sonnet`) или полное имя |
| `--fallback-model <model>` | Автопереход на резервную модель при перегрузке (список через запятую; только с `--print`) |
| `--effort <level>` | Уровень усилий: low, medium, high, xhigh, max |
| `--agent <agent>` | Агент для сессии (переопределяет настройку `agent`) |
| `--agents <json>` | JSON с определениями кастомных агентов |
| `--betas <betas...>` | Beta-заголовки в запросах к API (только для API-key пользователей) |
| `--max-budget-usd <amount>` | Максимальная сумма расходов на API (только с `--print`) |
| `--autocompact <auto\|tokens>` | Размер окна автокомпакта (`auto` или 100k–1M токенов) |

### 3.3. Промпты и контекст

| Флаг | Описание |
|---|---|
| `--system-prompt <prompt>` | Системный промпт сессии |
| `--append-system-prompt <prompt>` | Добавить текст к системному промпту по умолчанию |
| `--add-dir <directories...>` | Дополнительные директории, доступные инструментам |
| `--file <specs...>` | Файлы-ресурсы, скачиваемые на старте: `file_id:relative_path` |
| `--exclude-dynamic-system-prompt-sections` | Перенести машинно-зависимые секции (cwd, env, memory paths, git status) из системного промпта в первое сообщение — лучше переиспользуется prompt-кэш |

### 3.4. Права и инструменты

| Флаг | Описание |
|---|---|
| `--permission-mode <mode>` | `acceptEdits`, `auto`, `bypassPermissions`, `manual`, `dontAsk`, `plan` |
| `--allowedTools, --allowed-tools <tools...>` | Разрешённые инструменты (например `"Bash(git *)" Edit`) |
| `--disallowedTools, --disallowed-tools <tools...>` | Запрещённые инструменты |
| `--tools <tools...>` | Ограничить набор встроенных инструментов (`""` — отключить все, `default` — все) |
| `--dangerously-skip-permissions` | Полный обход проверок прав (только для песочниц без интернета) |
| `--allow-dangerously-skip-permissions` | Разрешить обход как опцию, не включая его по умолчанию |

### 3.5. Неинтерактивный режим

| Флаг | Описание |
|---|---|
| `-p, --print` | Вывести ответ и выйти (для пайпов). Диалог доверия к workspace пропускается |
| `--output-format <format>` | `text` (по умолчанию), `json`, `stream-json` |
| `--input-format <format>` | `text` (по умолчанию) или `stream-json` |
| `--json-schema <schema>` | JSON Schema для валидации структурированного вывода |
| `--include-partial-messages` | Частичные чанки сообщений по мере поступления |
| `--include-hook-events` | Все события жизненного цикла хуков в потоке вывода |
| `--forward-subagent-text` | Пробрасывать текст и thinking сабагентов с `parent_tool_use_id` |
| `--replay-user-messages` | Возвращать пользовательские сообщения из stdin обратно в stdout |
| `--prompt-suggestions [value]` | Подсказки следующего промпта (в print/SDK — сообщение `prompt_suggestion`) |

### 3.6. Конфигурация и расширения

| Флаг | Описание |
|---|---|
| `--settings <file-or-json>` | Путь к JSON-файлу настроек или JSON-строка |
| `--setting-sources <sources>` | Источники настроек через запятую: `user`, `project`, `local` |
| `--mcp-config <configs...>` | Загрузить MCP-серверы из JSON-файлов или строк |
| `--strict-mcp-config` | Использовать только серверы из `--mcp-config`, игнорируя остальные |
| `--plugin-dir <path>` | Загрузить плагин из директории или `.zip` только для этой сессии |
| `--plugin-url <url>` | Скачать плагин `.zip` по URL только для этой сессии |
| `--disable-slash-commands` | Отключить все скиллы |

### 3.7. Диагностика и минимальные режимы

| Флаг | Описание |
|---|---|
| `-d, --debug [filter]` | Debug-режим с фильтром категорий (например `api,hooks` или `!1p,!file`) |
| `--debug-file <path>` | Писать debug-логи в файл (неявно включает debug) |
| `--verbose` | Переопределить настройку verbose |
| `--safe-mode` | Отключить все кастомизации (CLAUDE.md, скиллы, плагины, хуки, MCP, команды, агенты, output styles, воркфлоу, темы, keybindings). Политики администратора продолжают действовать |
| `--bare` | Минимальный режим: без хуков, LSP, синка плагинов, атрибуции, автопамяти, фоновых префетчей, чтения keychain и автообнаружения CLAUDE.md. Аутентификация строго через `ANTHROPIC_API_KEY` или `apiKeyHelper` |

## Оговорки

- Пометка «описания нет» стоит там, где команда есть в реестре, но её объект собирается
  динамически или спрятан за фиче-флагом. Описание не выдумывалось.
- Часть команд не показывается в меню `/help`: они гейтятся флагами, планом подписки,
  типом терминала или внутренними условиями.
- Список привязан к версии 2.1.233 — при обновлении CLI набор команд меняется.
